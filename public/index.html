Ce que fait cette interface

Elle aide à structurer une lecture simple : ce qui est déclaré, ce qui semble manquer, ce qui reste à vérifier, ce qui reste local dans le navigateur, et ce que l'utilisateur peut faire ensuite.

  • mentions légales ;
  • politique de confidentialité ;
  • cookies, traceurs et stockage local ;
  • liens publics Pappers / Annuaire / API construits depuis l'URL ou le nom saisi ;
  • import par collage d'un résultat public visible ;
  • entité réelle déclarée, SIREN, SIRET, adresse et source externe ;
  • emplacement exact des informations sur le site audité ;
  • validation publique SSF-IRS : SAT, UNSAT, UNKNOWN ;
  • journal local visible, exportable, restaurable et effaçable ;
  • droits RGPD et moyens de contact ;
  • cohérence entre les documents et le fonctionnement observable.

Audit déclaratif minimal

Cette version privilégie les sources publiques accessibles sans compte ni jeton : liens directs, API ouverte et import par collage. Les champs restent toujours modifiables.

L'adresse reste visible localement. Elle sert aussi à construire des liens publics de recherche société.

Récupération publique société

Action volontaire : l'interface construit des liens publics Pappers / Annuaire / API depuis l'URL auditée ou depuis un terme société. L'utilisateur peut ouvrir ces liens, copier les données visibles, puis les réinjecter dans la logique SSF-IRS.

1. ConstruireTerme société, SIREN, SIRET, URL ou indice de domaine.
2. OuvrirPappers public, Annuaire Entreprises, API ouverte ou Google-Pappers.
3. CollerRésultat visible : dénomination, SIREN, SIRET, forme, activité.
4. RéinjecterPréremplissage puis SSF-IRS SAT / UNSAT / UNKNOWN.

Journal local des actions

Cette interface tient un carnet local dans le navigateur. Il montre ce que cette page écrit localement : actions utiles, lecture générée, compteur, statuts SSF-IRS et dernier audit restaurable.

Dans cette version, ces éléments ne sont pas transmis automatiquement à un serveur. Les requêtes automatiques ne sont lancées qu'après action de l'utilisateur.

Où ? Dans le navigateur utilisé, pour cette interface.
Quoi ? Journal des actions, dernier audit local et dernier jeu de liens publics construit.
Contrôle Afficher, exporter, restaurer, effacer.

Limites

Cette interface ne produit pas de verdict juridique automatique. Elle aide à distinguer les faits observables, les déclarations trouvées, les données manipulées, leur emplacement, les requêtes lancées par l'utilisateur, les traces locales, les zones floues, le niveau de vigilance documentaire et les actions possibles.
