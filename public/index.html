SITE_RESULT + LEGAL_ENTITY + DATA_JOURNEY + DATA_RIGHTS + RISK_SIGNALS = PUBLIC_UNDERSTANDING

Ce que fait cette interface

Elle aide à structurer une lecture simple : ce qui est déclaré, ce qui semble manquer, ce qui reste à vérifier, et ce que l'utilisateur peut faire ensuite.

  • mentions légales ;
  • politique de confidentialité ;
  • cookies, traceurs et stockage local ;
  • entité réelle déclarée et cohérence apparente avec un registre officiel ;
  • acteurs et destinataires déclarés ;
  • droits RGPD et moyens de contact ;
  • cohérence entre les documents et le fonctionnement observable.

Audit déclaratif minimal

Cette version ne visite pas automatiquement le site renseigné. Elle construit une lecture locale à partir des éléments observés ou indiqués par l'utilisateur.

L'adresse reste locale dans cette version. L'utilisateur peut effacer le journal à tout moment.

Journal local des actions

Cette interface enregistre localement les actions utiles dans localStorage afin de montrer à l'utilisateur ce qui se passe dans son navigateur. Ce journal n'est pas transmis à un serveur par cette version.

Aucun affichage demandé.

Limites

Cette interface ne produit pas de verdict juridique automatique. Elle aide à distinguer les faits observables, les déclarations trouvées, les données manipulées, les zones floues, le niveau de vigilance documentaire et les actions possibles.
