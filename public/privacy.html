Confidentialité

Le journal reste lisible et contrôlable.

Cette notice décrit le comportement de la version publique minimale : traitement local, journal visible, dernier audit restaurable et effacement utilisateur.

Ce que l'interface ne fait pas

  • aucun compte utilisateur ;
  • aucune publicité ;
  • aucun SDK publicitaire ;
  • aucun outil d'analytics externe ;
  • aucun envoi automatique du journal local vers un serveur ;
  • aucune requête automatique vers Annuaire Entreprises, Sirene, RNE, Pappers ou data.gouv dans cette version ;
  • aucune collecte volontaire de dossiers personnels ou de pièces administratives.

Carnet local du navigateur

La page peut enregistrer localement deux éléments dans le navigateur : un journal d'actions et le dernier audit local.

Ce stockage sert à rendre visible le comportement de l'interface : ce qui a été cliqué, ce qui a été généré, quels statuts ont été produits et quel audit peut être restauré.

Ces éléments peuvent persister après fermeture de la page jusqu'à effacement par l'utilisateur ou suppression par le navigateur.

Clés locales utilisées

La version actuelle peut utiliser les deux clés suivantes dans le stockage local du navigateur :

rgpd-data-journey-audit:local-action-log
rgpd-data-journey-audit:last-local-audit

La première clé conserve le journal des actions. La seconde clé conserve le dernier audit local afin de pouvoir le restaurer dans le formulaire et dans la restitution.

Données saisies

La version actuelle peut permettre à l'utilisateur de renseigner une adresse de site ou des observations manuelles. Ces informations servent à générer une lecture locale dans le navigateur.

Les champs société — dénomination, forme juridique, SIREN, SIRET, adresse déclarée, source externe et emplacement sur le site — sont utilisés localement pour produire une restitution SSF-IRS SAT / UNSAT / UNKNOWN.

Lorsque l'utilisateur génère une lecture locale, le dernier audit peut être conservé dans le navigateur pour affichage, vérification, restauration ou effacement.

Contrôles utilisateur

  • afficher une explication simple du stockage local ;
  • voir ce qui est stocké par cette interface ;
  • afficher le journal local ;
  • exporter le journal au format JSON ;
  • restaurer le dernier audit local ;
  • effacer le journal local ;
  • effacer toutes les données locales de cette interface.

Affichage et validation locale

Le compteur de vigilance, le pourcentage, l'aiguille, les statuts SSF-IRS et le tableau société sont calculés dans le navigateur à partir des informations indiquées par l'utilisateur.

Le résultat ne constitue pas une certification, une preuve de fraude ou un avis juridique. Il s'agit d'une lecture documentaire destinée à orienter la vigilance.

Infrastructure

Comme tout site web, l'hébergeur des fichiers publics peut traiter les données techniques nécessaires à la connexion, notamment l'adresse IP, selon ses propres conditions.

Principe

Pas de profilage, pas de transmission applicative par défaut, pas de donnée personnelle réelle dans le dépôt public. Les traces locales sont visibles, restaurables et effaçables par l'utilisateur.
